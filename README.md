# Siebly agent skills

Agent skills for AI coding agents working with [Siebly](https://siebly.io)'s open-source JavaScript and TypeScript SDKs for cryptocurrency exchange APIs.

## Skills

| Skill | What it helps with |
| --- | --- |
| [`siebly-crypto-exchange-api`](skills/siebly-crypto-exchange-api/SKILL.md) | Building, inspecting or changing Node.js and JavaScript integrations with exchange REST and WebSocket APIs using Siebly SDKs |

The canonical copy is also published at [siebly.io/.well-known/agent-skills/siebly-crypto-exchange-api/SKILL.md](https://siebly.io/.well-known/agent-skills/siebly-crypto-exchange-api/SKILL.md).

## Install

With the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add sieblyio/agent-skills
```

Or copy `skills/siebly-crypto-exchange-api` into your agent's skills folder (for example `.claude/skills/` or `.agents/skills/`).
